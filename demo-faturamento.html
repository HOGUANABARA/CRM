Como funciona

Fluxo do fechamento por período de pagamento
  1. Carregar a base — o painel lê a aba unificada com todos os meses.
  2. Escolher o período de pagamento — ex.: 30/07/2026 a 15/08/2026. O painel calcula, pela regra de vencimento de cada médico, qual competência vence dentro do período, e monta a lista organizada por competência e data de pagamento.
  3. Revisar cada médico — apuração automática da competência dele + lançamentos manuais.
  4. Aprovar e acompanhar — demonstrativo para NF, ciclo Apurado → Aprovado → Enviado → NF → Financeiro → Pago.
  5. Exportar — CCF (.xlsx) no layout atual. "Salvar fechamento" guarda o andamento para reabrir depois.
